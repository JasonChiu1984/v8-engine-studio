# V8 引擎觀測室

以 Three.js 製作的 V8 引擎剖視模型。可從任意角度觀察 360° 旋轉、逐步拆解零件，並查看曲軸、連桿、活塞與凸輪軸的連動。模型由程式依參考圖重建，適合機構展示。

## 開啟網頁

下載 [V8_Engine_Studio.html](./V8_Engine_Studio.html)，用 Chrome、Safari 或 Edge 開啟。Three.js、模型幾何、材質及操作介面都封裝在 HTML 內，可離線使用，無需安裝套件或啟動伺服器。若在 GitHub 看到 HTML 原始碼，可使用 **Download raw file** 下載。

| 功能 | 操作 |
| --- | --- |
| 旋轉與縮放 | 滑鼠拖曳旋轉、滾輪縮放。觸控裝置可用單指旋轉、雙指縮放。 |
| 爆炸視圖 | 按「爆炸圖」展開零件，或調整「拆解程度」滑桿（0–100%）。按「組裝」收回。 |
| 機構運轉 | 切換「引擎運轉」，可選擇 0.5×、1× 或 2× 播放速度。 |
| 引擎音浪 | 點開「引擎音浪」，調整 800–6,500 rpm 基準轉速。四行程 V8 每轉四次排氣脈衝；播放速度也會改變音高。停機或切換至背景分頁時會淡出。機構以慢動作顯示，便於觀察。 |
| 檢視零件 | 選擇透視、正面、側面或俯視。可開啟零件標示，或在模型上點選零件辨識。 |
| 下載 3D 模型 | 在網頁按「下載 3D 模型」取得 ZIP，或直接下載 [V8_Engine.glb](./V8_Engine.glb)。 |

## 模型與渲染

- Three.js r180 使用 WebGL 2 渲染，並在 WebGL 無法啟動時以 Canvas 2D 繪製相同的 3D 幾何。
- 模型包含兩排汽缸、八組活塞與連桿、曲軸、凸輪軸、汽門、進排氣總成、皮帶輪及油底殼。
- GLB 可匯入 Blender，包含 `01_Orbit_360`（8 秒）、`02_Exploded_assembly`（5 秒）和 `03_Powertrain_cycle`（2 秒）三段動畫。
- 已用桌面與手機尺寸驗證軟體渲染路徑的旋轉、縮放、拆解、視角預設與點選。GLB 通過檔案結構及動畫資料檢查。
- 內嵌的 Three.js 依 MIT 授權提供，版權及授權文字保留在 HTML 中。
